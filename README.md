# 生活效率工具箱

一个基于 Web 的个人效率工具集合，包含待办清单、笔记、记账等功能，帮助用户高效管理日常生活。

## 📁 项目结构

```
todo-list/
├── index.html          # 主页面
├── style.css           # 样式文件
├── script.js           # 业务逻辑
├── README.md           # 项目说明
└── .github/
    └── workflows/
        └── deploy.yml  # 部署配置
```

## ✨ 功能特性

### 1. 待办清单 ✅
- 添加、编辑、删除待办任务
- 任务优先级设置（高/中/低）
- 截止时间提醒
- 任务完成状态切换
- 成就徽章系统
- 任务筛选（全部/未完成/已完成）

### 2. 笔记工具 📒
- 创建、编辑、删除笔记
- 笔记收藏功能
- 自定义笔记颜色
- 笔记列表展示

### 3. 记账工具 💰
- 添加收支记录
- 多分类支持（餐饮、交通、购物等）
- 收支统计面板
- 记录筛选

### 4. 关于我 👤
- 个人简历展示
- 教育经历
- 专业技能
- 项目作品展示

### 5. 进阶功能
- **数据持久化**: 所有数据保存到 localStorage
- **数据导入/导出**: 支持 JSON 格式备份与恢复
- **主题切换**: 深色/浅色模式
- **键盘快捷键**: 快速操作支持

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `1` / `T` | 切换到待办清单 |
| `2` / `N` | 切换到笔记 |
| `3` / `F` | 切换到记账 |
| `4` / `A` | 切换到关于我 |
| `D` | 切换主题 |
| `Ctrl+E` | 导出数据 |

## 🚀 快速开始

### 开发环境
```bash
# 克隆仓库
git clone https://github.com/suble7/todo-list.git

# 进入项目目录
cd todo-list

# 启动本地服务器
python -m http.server 8080

# 访问地址
http://localhost:8080
```

### 生产部署
项目已配置 GitHub Actions 自动部署，推送到 `main` 分支后自动部署到 GitHub Pages。

## 🛠️ 技术栈

- **前端框架**: HTML5 + CSS3 + JavaScript (ES6+)
- **样式**: Tailwind CSS 3
- **图标**: Font Awesome 6
- **构建工具**: 原生 JavaScript，无需构建工具

## 📱 响应式设计

项目支持桌面端和移动端访问，布局自适应不同屏幕尺寸。
