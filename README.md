# ✅ 待办清单工具 - 生活效率工具箱

一款基于 Web 的待办事项管理工具，帮助你高效管理日常任务！

## ✨ 功能特性

### 核心功能
- **添加待办事项**：支持输入任务内容、截止时间、优先级（高/中/低）
- **标记状态**：点击圆形按钮切换已完成/未完成状态
- **编辑任务**：修改任务内容、截止时间、优先级
- **删除任务**：二次确认后删除
- **筛选功能**：全部/未完成/已完成三种筛选
- **本地存储**：使用 localStorage 持久化数据

### 游戏化元素
- **完成进度条**：实时显示任务完成百分比，带闪光动画效果
- **激励提示**：完成任务时随机显示正向激励语句
- **成就系统**：8个待办成就徽章

|------|------|----------|
| 🌱 | 初次尝试 | 完成第一个待办任务 |

| 🎯 | 渐入佳境 | 完成10个待办任务 |
| 🚀 | 效率达人 | 完成25个待办任务 |

| 🚨 | 紧急救援 | 完成一个高优先级任务 |

## 🚀 快速开始

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/suble7/todo-list.git
cd todo-list

# 使用任意静态服务器运行
python -m http.server 8080
```

然后访问 `http://localhost:8080`

### 直接打开

直接用浏览器打开 `index.html` 文件即可运行（无需服务器）

## 🛠️ 技术栈

- HTML5 + CSS3 + JavaScript (ES6+)
- Tailwind CSS 3（CDN）
- Font Awesome 6（图标）
- localStorage（数据持久化）

## 📱 响应式设计

支持桌面端和移动端访问，界面自适应不同屏幕尺寸。
